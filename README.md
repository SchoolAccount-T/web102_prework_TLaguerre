## About
This project is a web-based platform designed to showcase a variety of crowdfunding campaigns for games. It provides a user-friendly interface to browse through different game projects, each with detailed information about its funding status, goals, and backer count. The platform is ideal for anyone interested in the latest trends in the gaming industry, especially in the realm of crowdfunded projects.

## Features
- **Dynamic Game Display:** The platform dynamically loads and displays a list of games from a JavaScript data source.
- **Detailed Game Information:** Each game listing includes the name, a descriptive summary, the amount pledged, the funding goal, and the number of backers.
- **Visual Appeal:** Each game is represented by an image, providing a quick visual reference.
- **Statistical Overview:** The platform includes a statistics section that provides an overview of all games, including the total number of contributions, total funds raised, and the total number of games.
- **Responsive Design:** The layout is designed to be responsive and user-friendly, with a flexible grid system that adapts to different screen sizes.

## Getting Started
To get started with this project, you will need a modern web browser that supports HTML5, CSS3, and JavaScript.

## Usage
To use the platform, simply open the `index.html` file in your web browser. The page will automatically load the game data and display it in a structured and visually appealing manner.

## Styling
The project uses a custom stylesheet (`style.css`) to create a unique and engaging user experience. The styling includes:
- **Font:** The 'Cabin' font is used for a clean and readable text display.
- **Color Scheme:** A cool color palette with shades of blue and gray provides a professional and modern look.
- **Interactive Elements:** Hover effects on game cards provide visual feedback to the user.
- **Layout:** A flexbox-based layout ensures that the content is well-organized and responsive.
